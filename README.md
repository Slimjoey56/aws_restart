# AWS re/Start Learning Repository

A collection of introductory Python exercise files created during cloud-computing learning and practice.

## Purpose

This repository preserves hands-on exercises and code experiments from an AWS Cloud9-based learning environment. The visible Python files are numbered exercises rather than a packaged application.

## Repository Contents

- Python exercise files (`Untitled1.py` through `Untitled7.py`)
- AWS Cloud9 workspace configuration
- This project README

## Working with the Exercises

1. Clone the repository.
2. Open the Python files in an editor.
3. Review and run each exercise independently with Python 3.
4. Add a short description and example output to each exercise as the work is refined.

```bash
python --version
python Untitled1.py
```

Replace the example filename with the exercise you want to run.

## Scope

This repository is a learning archive. It should not be interpreted as a production AWS deployment or as evidence that every AWS service has been implemented.
